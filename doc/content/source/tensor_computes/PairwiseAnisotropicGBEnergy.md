# PairwiseAnisotropicGBEnergy

!syntax description /TensorComputes/Solve/PairwiseAnisotropicGBEnergy

`PairwiseAnisotropicGBEnergy` evaluates a TorchScript model on the normal between a pair of grains' order-parameter gradients, and stores both the resulting scalar grain-boundary energy and its derivatives with respect to each incoming gradient in output buffers.

## Overview

The object takes two vector-valued gradient buffers, `grad_grain1_buffer` and `grad_grain2_buffer` (each with trailing component dimension `3`, typically generated by [GradientVector.md]), and computes the interface normal

\begin{equation}
\hat{n} = \frac{\nabla \eta_1 - \nabla \eta_2}{|\nabla \eta_1 - \nabla \eta_2|}
\end{equation}

A point is only evaluated by the TorchScript model if all three of $|\nabla \eta_1|$, $|\nabla \eta_2|$, and $|\nabla \eta_1 - \nabla \eta_2|$ clear a gradient-magnitude threshold derived from `interface_width`. The third condition matters at triple junctions, where two order parameters can rise together against a third grain and their difference nearly vanishes even though each gradient individually clears the threshold.

Outside this masked region, the derivative buffers (`dsigma_dgrad_grain1`, `dsigma_dgrad_grain2`) are zero, since there is no boundary to exert a torque. The energy buffer is instead filled with the largest energy value measured anywhere in the domain (or `1.0` if no interface point was found anywhere), to avoid introducing an artificial low-energy region in the bulk.

To bound peak memory usage on large grids, evaluation is chunked: the domain is processed `chunk_size` points at a time, with masking, TorchScript evaluation, and autograd all performed per chunk.
