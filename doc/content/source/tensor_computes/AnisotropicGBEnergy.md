# AnisotropicGBEnergy

!syntax description /TensorComputes/Solve/AnisotropicGBEnergy

AnisotropicGBEnergy evaluates a TorchScript model on grain-boundary normal vectors and stores both the resulting scalar grain-boundary energy and its derivative with respect to the incoming normal tensor in output buffers.

## Overview

The object expects a vector-valued tensor buffer with trailing component dimension `3`, typically generated by `GradientVector`. The input is flattened to `(N, 3)`, normalized row-wise in C++, passed to the TorchScript module, and then masked back to zero in regions where the incoming vector magnitude is effectively zero. The class also uses autograd to compute `dsigma_dn`, which is written to a second tensor buffer with the same shape as the original normal tensor.
