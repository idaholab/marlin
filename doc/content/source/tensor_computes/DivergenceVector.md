# DivergenceVector

!syntax description /TensorComputes/Solve/DivergenceVector

Computes the divergence of a vector tensor (value_dimensions = '3'). An optional
prefactor can be applied via [!param](/TensorComputes/Solve/DivergenceVector/factor).
